06 / 24

Wallets and Signing: Your Digital Debit Card

Public address = account number
Share it freely. Anyone can send you money with it.
Private key = your secret PIN
It approves transactions and signs you into apps. Never share it.
Signing = pressing approve
You say yes to moving money or taking an action.
Building? Use a separate burner wallet with free test tokens on devnet. Keep real money far away from your code.
Notes. Plain language: address = account number, private key = PIN, signing = approve. Strong emphasis on burner wallets and devnet tokens.
Sources. https://solana.com/wallets

07 / 24

How Solana Apps Work: Code is Separate from Data

Programs are the apps
Pure instructions. Deploy once, used by everyone.
Accounts are the files
Balances and user info live here, passed in on every run.
One app, millions of users
Each user simply brings their own files.
Notes. Apps vs. Files. Programs hold logic only. Accounts hold balances and user info and are passed into the program when it runs.
Sources. https://solana.com/docs/core/accounts

Mental model 4
09 / 24

Everything is an Account, and How App Vaults Work

Your wallet
Your address and SOL balance
Token balances
How much of each token you hold
App settings
An app's config and user data
App vaults
Funds an app holds for its users
A vault address is born from the app's ID plus a seed, so only that program's code can move funds out. No human holds a key to lose.
Notes. Wallets, token balances, settings and vaults are all accounts. PDAs are addresses derived from the program ID plus seeds, with no private key; only the program can sign for them.
Sources. https://solana.com/docs/core/accounts https://solana.com/docs/core/pda
Alpenglow
10 / 24

Alpenglow: Final in ~150ms, Faster Than a Blink

Old way
Validators voted by sending transactions, and finality took many rounds.
New way
Validators vote directly to each other, off-chain, and bundle votes into certificates.
Result
Blocks become final in as little as one round. Irreversible in about 150ms.
Live on mainnet since Oct 21, 2026solana.com/upgrades/alpenglow ↗
Notes. Last week's Alpenglow mainnet upgrade, activated Oct 21, 2026 in epoch 1064. Votes moved off-chain into certificates; finality from about 12.8s to about 150ms.
Sources. https://solana.com/upgrades/alpenglow
When you build
11 / 24

What Alpenglow Means When You Build

Your programs: unchanged
Same SVM, transactions, fees and account model.
Blocks: no more vote traffic
Votes left the block, so they no longer take up space.
Your reads: go straight to finalized
The strongest guarantee now costs no extra wait.
{ commitment: "finalized" }
Notes. Execution untouched. Vote transactions are gone from blocks. confirmed and finalized now describe the same state; point new code at finalized.
Sources. https://solana.com/upgrades/alpenglow
